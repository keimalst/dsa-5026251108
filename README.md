## ▶️ Cara Menjalankan

Pastikan **JDK** sudah terpasang, lalu masuk ke folder yang ingin dijalankan. Contoh untuk prelab Labwork 01:

```bash
cd src/lw01/prelab
javac *.java
java Main
```

> 💡 Jalankan dari dalam foldernya, karena program membaca berkas input (mis. `jobs.txt`) secara relatif dari folder tersebut.

## 🎯 Konsep yang Dipelajari

- 🧱 **Class, Object, & Reference**: bedanya cetakan, wujud, dan penunjuknya
- 🔒 **Encapsulation**: field `private`, akses lewat operasi yang tepat

- 🔁 **Overloading vs Overriding**: nama sama, maksud berbeda
- 🎭 **Polymorphism**: satu referensi, banyak perilaku saat *runtime*
